Perimeter Controls

Strict HTTP origin validation (`chrome-extension://`, `tauri://localhost`). Unauthorized cross-origin requests from drive-by websites are blocked at handshake.

Core Isolation

FastAPI binds strictly to loopback (`127.0.0.1`). API tokens are encrypted in the OS Credential Vault; logs automatically sanitize bearer keys.

Kill-Switch Safeguard

Global emergency `Esc` key immediately disarms all OS mouse/keyboard synthetic automation and halts active ReAct loops within 50ms.
